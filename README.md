# NBA Lineup Surprise Lab

Independent NBA analytics project exploring observed outcomes relative to statistical expectations, with an emphasis on shot-level performance and lineup context.

**Deployment status:** The original application file has not yet been committed to this repository. The repository currently contains documentation only.

## Research scope
- Observed versus expected shooting performance
- Lineup combinations and contextual results
- Offensive and defensive impact
- Unexpected player and team performance

These are research goals, not a claim that every feature is currently deployed.

## Publish
Upload the original Lineup Surprise Lab HTML file to the repository root as `index.html`. Then select **Settings → Pages → Deploy from a branch → main → /(root)**. After successful deployment, the expected URL is https://michaelonyemenam-ds.github.io/nba-surprise-lab/.

Do not commit private datasets, credentials, or proprietary tracking data.
